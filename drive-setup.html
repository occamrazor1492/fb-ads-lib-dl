Google Drive Setup Required

The Drive button is visible, but upload cannot work until this extension has a real Google OAuth Client ID.

Current manifest still contains the OAuth placeholder, so Chrome blocks the Drive connection flow.

Extension ID

Use this Chrome Web Store extension ID when creating the OAuth client:

enfijcghckbajcdnckjjcibiphimfipi

Steps

  1. Open Google Drive API and enable it.
  2. Open OAuth consent screen and add the drive.file scope.
  3. Open Credentials and create an OAuth Client ID with application type Chrome Extension.
  4. Paste the generated client ID into manifest.json, replacing REPLACE_WITH_GOOGLE_OAUTH_CLIENT_ID.apps.googleusercontent.com.
  5. Run ./scripts/package-extension.sh, reload the extension, and the popup button will become Connect Drive.

Scope

The extension uses https://www.googleapis.com/auth/drive.file. It can create and access files it uploads through the extension, not the user's entire Drive.
